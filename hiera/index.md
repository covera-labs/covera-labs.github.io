# Hiera

親子タスクとタイムラインで、計画を見渡すタスク管理アプリ。

大きなタスクを小さなタスクに分けて、タイムラインで「いつから・いつまで」を見渡せるiOSアプリです。データはお使いの端末の中だけに保存され、開発者が見ることはありません。
