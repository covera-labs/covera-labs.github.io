# 利用規約

この利用規約（以下「本規約」といいます）は、Covera Labs（以下「当方」といいます）が提供するiOSアプリ「Hiera」（以下「本アプリ」といいます）の利用条件を定めるものです。本アプリを利用する前に、本規約をお読みください。

## 第1条（適用と同意）

1. 本規約は、本アプリを利用するすべての方（以下「利用者」といいます）に適用されます。
2. 利用者は、本アプリを利用した時点で、本規約に同意したものとみなされます。
3. 本アプリの使用許諾には、Apple Inc.（以下「Apple」といいます）が定める「Licensed Application End User License Agreement」（以下「標準EULA」といいます）が適用されます。本規約は、標準EULAに加えて本アプリの利用条件を定めるものです。本規約と標準EULAの内容が矛盾する場合は、法令上許される範囲で本規約が優先します。

## 第2条（未成年者の利用）

未成年の方は、親権者などの法定代理人の同意を得たうえで本アプリを利用してください。特に有料機能の購入は、必ず法定代理人の同意を得てから行ってください。

## 第3条（有料機能）

1. 本アプリは無料で利用できます。ただし、一部の機能には無料で使える範囲（進行中の計画の数、タイムラインで見られる期間など）を設けています。
2. 当方は、無料で使える範囲を外し、ウィジェットと iCloud での同期などを使えるようにする有料機能「Hiera Pro」（以下「Hiera Pro」といいます）を、App Storeを通じて買い切りで提供します。内容と価格は、本アプリ内の購入画面に表示します。
3. 代金の支払いは、Appleの定める方法により、利用者のApple IDに登録された支払方法で行われます。
4. Hiera Pro は、購入手続きが完了した時点から利用できます。購入は1回限りで、自動で更新されたり、追加の請求が行われたりすることはありません。
5. 同じApple IDでサインインした端末では、本アプリの設定の「購入を復元」から、追加の支払いなしで Hiera Pro を利用できます。
6. 返金の可否は、Appleの定める規定に従ってAppleが判断します。当方は、返金の手続きを直接行うことができません。当方の責めに帰すべき事由により Hiera Pro を利用できない場合は、当方は速やかに修正に努めるとともに、Appleへの返金申請の方法をご案内します。
7. 返金などにより Hiera Pro を利用できなくなった場合でも、それまでに入力したデータは削除されず、本アプリで閲覧と編集ができます。ただし、iCloud での同期は停止します。

## 第4条（データの保存とバックアップ）

1. 本アプリに入力されたデータは、利用者の端末の中に保存されます。Hiera Pro の「iCloud で同期」をオンにした場合は、利用者ご自身のiCloudにも保存されます。当方は、利用者のデータを保管していません。
2. 次の場合などに、データが失われるおそれがあります。必要に応じて、端末のバックアップを取ってください。
   - 「iCloud で同期」をオンにしていない状態で、本アプリを削除した場合や端末を変更した場合（端末のバックアップから復元した場合を除きます）
   - iCloud上の本アプリのデータを削除した場合
   - 端末やiCloudに障害が発生した場合
3. 当方は、利用者のデータを復元することができません。
4. 本アプリは、利用者が入力した予定や期限を表示するためのツールです。期限の管理は、利用者ご自身の責任で行ってください。
